# Sistema de Asistencias de Visitantes - Biblioteca

Este proyecto es un sistema básico para gestionar las asistencias de visitantes en una biblioteca. Actualmente es un esqueleto con HTML y CSS.

## Estructura del Proyecto

- `src/`: Código fuente
  - `index.html`: Página principal
  - `css/styles.css`: Estilos
  - `js/app.js`: Scripts básicos
  - `assets/`: Imágenes y recursos
- `public/`: Archivos estáticos para servidor
- `docs/`: Documentación

## Cómo usar

1. Abre `src/index.html` en un navegador.
